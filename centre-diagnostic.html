Installez l'agent sur le PC à diagnostiquer. Il se connectera automatiquement à cette plateforme et enverra les données en temps réel toutes les 3 secondes. L'agent reçoit aussi les commandes de contrôle à distance depuis cette interface.

📋 Comment utiliser l'agent ?
  1. Téléchargez le fichier agent_diag.py
  2. Installez Python 3.10+ sur le PC cible (python.org)
  3. Double-cliquez sur agent_diag.py
  4. L'agent se connecte automatiquement
  5. Le PC apparaît ici en temps réel
  6. Utilisez les boutons de contrôle pour envoyer des commandes
